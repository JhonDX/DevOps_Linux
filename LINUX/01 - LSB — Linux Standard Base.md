### 

O **LSB (Linux Standard Base)** foi um padrão criado para aumentar a **compatibilidade entre diferentes distribuições Linux**.

Ele definia padrões para:

- Estrutura do sistema
- Bibliotecas
- Comandos
- Pacotes
- Scripts de inicialização
- Comportamento de aplicações

**Objetivo:** permitir que softwares desenvolvidos para Linux tivessem maior compatibilidade entre diferentes distribuições.

**Resumo:**  
**FHS → organiza os diretórios.**  
**LSB → padroniza aspectos do sistema para melhorar a compatibilidade entre distribuições.**
